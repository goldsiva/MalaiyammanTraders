Malaiyamman Traders Static Site
--------------------------------

Setup:
1. Open products.html in your browser to view the catalog.
2. Each product has an "Add to Cart" button.
3. Cart summary appears in the header (top right).
4. Click "View Cart" to go to cart.html.
5. Fill in customer details and click "Place Order".
6. WhatsApp will open with a pre-filled order message sent to the shop number.

Configuration:
- WhatsApp number is stored in style.js
- Edit SHOP_NUMBER in style.js to your own number (include country code, no + sign).
- Example: India number → "919812345678"

Branding:
- logo.png → header/footer logo
- favicon.ico → browser tab icon

Customization:
- style.css → edit colors, fonts, or layout
- You can add/remove categories by updating products.xlsx and regenerating.

Enjoy your new interactive catalog!
